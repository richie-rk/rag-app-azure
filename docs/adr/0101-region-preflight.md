# ADR 0101: Region preflight

- **Status:** Accepted
- **Date:** 2026-10-21; amended 2026-10-30 (`githubPrivateNetworkingRegions` read only under the private-networking option, ADR 0122)
- **Decided by:** Product owner and architect
- **Specified in:** 83-infrastructure.md, 81-config.md, 84-testing.md, 86-operations.md
- **Related ADRs:** 0005, 0048, 0061, 0062, 0095, 0096, 0098, 0099, 0100, 0102, 0112, 0114, 0120, 0122, 0135, 0138, 0140

## Context

Each environment runs in one region, set by `location` in `infra/env/<env>.json` (default `eastus2`). Provisioning must stop before it changes anything when the subscription or the region can't host the environment: a resource provider that isn't registered, a service the region doesn't offer, Linux Elastic Premium with too little scale-out, an AI feature the product depends on (Prompt Shields for source screening, the semantic ranker for retrieval, the Document Intelligence layout model for the recursive method), a pinned model version under its deployment's type (ADR 0099, ADR 0100), model quota, or the availability zones that `prod`'s zone-redundant storage and Cosmos DB need (ADR 0102). Each pinned model version is checked against its own deployment type in the region and fails when it is deprecated for the subscription, isn't offered for that type in the region, or retires within 6 months. Environment values are validated at the same point, so a configuration mistake surfaces as a named failure rather than a half-provisioned environment.

Several of these features have no resource property that ARM validation or what-if would test, and some have no GA availability API at all. Vendor facts (checked 2026-10-14 unless stated):

- Linux Elastic Premium's maximum scale-out per plan is 100 in East US, East US 2, Central US, South Central US, West US, Canada Central, North Europe, West Europe, UK South and UAE North, 60 in France Central, 40 in Australia East and 20 in most other regions; it isn't offered in Australia Central 2 or South India.
- Prompt Shields on Content Safety resources is offered in canadaeast, centralus, eastus, eastus2, northcentralus, southcentralus, westus2, westus3, francecentral, polandcentral, switzerlandnorth, westeurope, australiaeast, japaneast, koreacentral, southeastasia and southindia; the semantic ranker is "available in select regions"; Document Intelligence publishes its layout model's regions as a table. None of the three has a GA availability API.
- Models API: `GET /subscriptions/{sub}/providers/Microsoft.CognitiveServices/locations/{location}/models?api-version=2024-10-01` returns each model's `lifecycleStatus` (`GenerallyAvailable`; `Deprecating`, the documentation's Deprecated; `Deprecated`, meaning retired), `deprecation.inference` and each SKU's `deprecationDate`. A deprecated version can still be deployed by a subscription that has deployed it, never by a new one. Model Capacities API: `GET /subscriptions/{sub}/providers/Microsoft.CognitiveServices/modelCapacities?api-version=2024-10-01&modelFormat=OpenAI&modelName=…&modelVersion=…` returns `skuName` and `availableCapacity` per location; Global Standard quota is pooled per subscription across regions since 2026-05-07.
- Subscriptions - List Locations (API 2022-12-01) returns each region's `availabilityZoneMappings` (logical to physical zones) (checked 2026-10-21).
- User-assigned managed identities created in Malaysia South can't hold federated credentials.
- Static Web Apps allows 2 custom domains on Free and 5 on Standard (the plans page; the quotas page lists 6 for Standard, so the check uses the lower value).
- Container Instances `locations/{location}/capabilities` (API 2026-07-01) returns, per resource type, OS and GPU, a region's `maxCpu` and `maxMemoryInGB`, and `locations/{location}/usages` its quota use.

## Decision

1. **The script.** `scripts/preflight/preflight.py`, Python 3.13 standard library plus `az` CLI calls through `subprocess`, run as `uv run --frozen python scripts/preflight/preflight.py --env <env> [--check all|models]` (default `all`). It reads `infra/env/<env>.json` and `infra/config/regions.json`, runs every check, prints one JSON report `{"env", "location", "checks": [{"name", "status": "pass" | "fail" | "warn", "detail"}]}` and exits 0 when no check fails, 2 when any fails.
2. **When it runs.** Before every provision: as its own step in the deploy job, which then sets `azd env set DOCCHAT_PREFLIGHT_DONE true`, and in the azd `preprovision` hook unless `DOCCHAT_PREFLIGHT_DONE` is `true`, so a local `azd provision` or `azd up` runs it too; in the pull-request what-if job against `dev`; and every night as `--check models` for `dev` and `prod` (ADR 0140).
3. **The checks**, each failing with its code:
   1. **Resource providers registered** (`az provider show -n <namespace> --query registrationState`): Microsoft.Web, Microsoft.Sql, Microsoft.DocumentDB, Microsoft.Storage, Microsoft.Search, Microsoft.CognitiveServices, Microsoft.KeyVault, Microsoft.ContainerRegistry, Microsoft.Network, Microsoft.OperationalInsights, Microsoft.Insights, Microsoft.ManagedIdentity, Microsoft.Security, Microsoft.EventGrid, Microsoft.AlertsManagement and Microsoft.ContainerInstance: `provider_not_registered`.
   2. **Services in the region**: the region appears in the provider's `resourceTypes[].locations` for `Microsoft.Web/sites`, `Microsoft.Web/serverFarms`, `Microsoft.Sql/servers`, `Microsoft.DocumentDB/databaseAccounts`, `Microsoft.Storage/storageAccounts`, `Microsoft.Search/searchServices`, `Microsoft.KeyVault/vaults` and `Microsoft.Network/privateEndpoints`, and `staticWebAppLocation` does for `Microsoft.Web/staticSites`: `service_not_in_region`.
   3. **AI account SKUs**: `POST /subscriptions/{sub}/providers/Microsoft.CognitiveServices/locations/{loc}/checkSkuAvailability?api-version=2026-07-01` with `{"skus": ["S0"], "kind": "<kind>", "type": "Microsoft.CognitiveServices/accounts"}` for the kinds `OpenAI`, `ContentSafety` and `FormRecognizer`, every `skuAvailable` true: `ai_sku_unavailable`.
   4. **Linux Elastic Premium**: `GET /subscriptions/{sub}/providers/Microsoft.Web/geoRegions?sku=ElasticPremium&linuxWorkersEnabled=true&api-version=2025-03-01` lists the region, and `ingestion.maxBurst` is at most the region's Linux maximum in `regions.json` (100 for eastus, eastus2, centralus, southcentralus, westus, canadacentral, northeurope, westeurope, uksouth and uaenorth; 60 francecentral; 40 australiaeast; 20 elsewhere; absent for australiacentral2 and southindia): `linux_premium_unavailable`.
   5. **Prompt Shields and the semantic ranker**: the region is in `regions.json` `promptShieldsRegions` (the 17 regions above) and `semanticRankerRegions` (from the AI Search semantic ranker region table): `prompt_shields_unavailable`, `semantic_ranker_unavailable`.
   6. **Model version per deployment type**, when `openAi.enabled` is true: the Models API for the region; each deployment is checked against its own type: `chat`, `chatSmall` and `tableSummary` against `type`, and for each `openAi.embeddingModels` entry `embed-query-<key>` against `queryType` and `embed-ingest-<key>` against `ingestionType`. No entry with `model.format` `OpenAI` and the pinned name and version: `model_version_not_offered`. `lifecycleStatus` `Deprecated`: `model_retired`. `Deprecating` while the environment's account (among the `kind: OpenAI` accounts of `rg-docchat-<env>`) holds no deployment of that model and version: `model_deprecated`. No `model.skus[].name` equal to the deployment's type: `model_sku_not_offered`. The matching SKU's `deprecationDate` or `model.deprecation.inference` earlier than today plus 183 days: `model_retires_soon`.
   7. **Quota**, when `openAi.enabled` is true: the Model Capacities API per model and version; capacities of one model, version and type are summed across the run's deployments, and the entry whose `location` is the region and whose `properties.skuName` is that type must show `properties.availableCapacity` of at least the sum minus the capacity of the same-named deployments already in the environment's account (read with `az cognitiveservices account deployment show`; 0 when absent): `quota_insufficient`, with the shortfall in units.
   8. **Availability zones**, for `prod` and `load` always and for `dev` when `api.zoneRedundant` or `sql.zoneRedundant` is `true`: `GET /subscriptions/{sub}/locations?api-version=2022-12-01` gives the region a non-empty `availabilityZoneMappings`: `availability_zones_unavailable`.
   9. **Operator allowlist**: every entry of `DOCCHAT_OPERATOR_IP_ALLOWLIST` is a dotted-quad IPv4 address outside RFC 1918, 100.64.0.0/10, 127.0.0.0/8 and 169.254.0.0/16, without a prefix length, and there are at most 20 entries: `allowlist_invalid`.
   10. **Federated credential region**: `rg-docchat-identity` isn't in `malaysiasouth`: `fic_region_unsupported`.
   11. **Document Intelligence layout**: the region is in `regions.json` `documentIntelligenceLayoutRegions`, the regions where the Learn region table lists the layout model on API 2024-11-30, copied at stage 0 with the page's `ms.date`: `document_intelligence_unavailable`.
   12. **Alert receivers** (`prod`): `DOCCHAT_OPS_ALERT_EMAILS` holds at least one address: `alert_receivers_missing`. Security alerts go to the bootstrap's `ag-docchat-security` action group, whose receivers the bootstrap requires (ADR 0114), so the preflight doesn't check them.
   13. **Load-generator capacity** (`load` only): `GET /subscriptions/{sub}/providers/Microsoft.ContainerInstance/locations/{loc}/capabilities?api-version=2026-07-01` holds an entry with `resourceType` `containerGroups`, `osType` `Linux`, `gpu` `None`, `capabilities.maxCpu` at least 4 and `capabilities.maxMemoryInGB` at least 8, and `…/locations/{loc}/usages?api-version=2026-07-01` leaves at least 4 standard cores free (`limit` minus `currentValue`): `container_capacity_unavailable`.
   14. **Static Web Apps custom domains**: `webCustomDomains` holds at most 2 host names when `web.sku` is `Free` and at most 5 when it is `Standard`: `custom_domains_exceed_plan`.
4. **The models-only mode.** `--check models` runs check 6 alone and adds a `warn` entry for each pinned version whose retirement date (the same two dates) falls within 274 days (9 months). The nightly model watch runs it as the `dev` deploy identity for both the `dev` and the `prod` environment files (ADR 0140).
5. **Region data.** `infra/config/regions.json` holds what no GA API answers: the Linux Elastic Premium maximum per region, `promptShieldsRegions`, `semanticRankerRegions` and `documentIntelligenceLayoutRegions` (and, for the bootstrap's `ci-runner` step under the private-networking option, `githubPrivateNetworkingRegions`, ADR 0122). A change to it is a reviewed pull request.
6. **Rights.** The custom role DocChat Preflight Reader (`63c4387a-e306-4ef7-9bfa-2e921c67f02b`), created by the bootstrap (ADR 0114) and assigned at the scope of every subscription in use to each deploy identity and to the pull-request identity, holds only `Microsoft.CognitiveServices/locations/models/read`, `Microsoft.CognitiveServices/locations/modelCapacities/read`, `Microsoft.CognitiveServices/modelCapacities/read`, `Microsoft.CognitiveServices/locations/usages/read`, `Microsoft.CognitiveServices/locations/checkSkuAvailability/action`, `Microsoft.CognitiveServices/accounts/read` and `Microsoft.CognitiveServices/accounts/deployments/read` (metadata only, so check 6 can find a deployment in any environment's account), `Microsoft.ContainerInstance/locations/capabilities/read`, `Microsoft.ContainerInstance/locations/usages/read`, `Microsoft.Web/geoRegions/read`, `Microsoft.Resources/subscriptions/read`, `Microsoft.Resources/subscriptions/locations/read` and `Microsoft.Resources/subscriptions/providers/read`.

## Alternatives considered

- **Rely on ARM validation and what-if.** Rejected: they fail late, inside a deployment that may already have created part of the environment, and test none of retirement dates, deprecation for a new subscription, model quota or the features without a resource property (Prompt Shields, the semantic ranker, Document Intelligence layout).
- **Check the region's model offering without the deployment type.** Rejected: a version offered as Global Standard may not be offered as Data Zone Standard or Standard in the same region, and each deployment's type is its own parameter (ADR 0099).
- **Fail on every `Deprecating` version.** Rejected: a subscription that has deployed a version can keep deploying it, so a redeploy of a running environment would be refused for no reason; the check passes when the environment's own account already holds that model and version, which is the subscription's right made visible to a metadata reader.
- **No retirement window, only the retired and deprecated states.** Rejected: an environment could deploy a version days before its retirement, after which the service would upgrade a chat-model deployment without review (`OnceCurrentVersionExpired`) and an embedding deployment would stop working (`NoAutoUpgrade`, ADR 0100).
- **A 12-month window.** Rejected: it would refuse a GA version from 6 months after its launch, a third of its 18-month life. The product owner's 6 months (183 days) leaves time to pin, test in `dev` and release, and the 274-day warning adds three months' notice before provisions start failing.
- **Hand-kept lists for every check.** Rejected: where an API answers (providers, locations, SKUs, Linux Elastic Premium regions, models, capacities, zones, container capabilities), the API is current; lists hold only the features without a GA availability API.
- **Management SDK packages in the script.** Rejected: the `az` CLI is on every runner and operator machine already, the checks are a few read calls, and a standard-library script needs no dependency of its own.

## Consequences

- Easier: a provision in a region that lacks a service, a feature, a model version for a deployment's type or enough quota fails in seconds with named codes and a JSON report, before any resource changes; the same command runs in CI, in the azd hook and on an operator's machine.
- The default region `eastus2` passes for the shipped files: it offers Static Web Apps, Linux Elastic Premium with 100 instances, Prompt Shields, the semantic ranker, availability zones and every default model as Global Standard.
- Retirement: the default gpt-5.6 versions (retiring 2028-01-11) start warning in April 2027 and failing provisions in July 2027, and `text-embedding-3-large` 1 (2028-02-09) in May and August 2027. From 2027-07-09, 12 months after the gpt-5.6 launch, a new account fails `model_deprecated` for those versions even in a subscription that could still deploy them, because the check accepts only a deployment already in the environment's own account; the remedy is the same newer pin that the 183-day rule requires days later.
- Harder: `regions.json` is kept current by hand; a stale list fails a region that has gained a feature (corrected by a pull request) or passes one that lost it, which the deployed tests then catch.
- Rights: the preflight role reads model, quota and account metadata across every subscription in use, including `prod`'s account from the `dev` deploy identity for the nightly run; it grants no data access and no write.
- Obligations: `83-infrastructure.md` lists the 14 checks with their APIs, scopes and codes (every failure exits 2); `81-config.md` describes `regions.json` and the environment values the script reads; `86-operations.md` holds the responses to `model_retires_soon` (pin the replacement version within the window, pass the preflight in `dev`, release), `quota_insufficient` (request quota or lower the capacity) and `provider_not_registered` (run the bootstrap's `providers` step).
- Tests (`84-testing.md`): unit tests against recorded Models API, Model Capacities, `checkSkuAvailability`, `geoRegions`, locations and Container Instances responses yield each code exactly when its condition holds; `model_retires_soon` fails at 182 days and passes at 184; `model_deprecated` passes when the account already holds the version; each embedding deployment is checked against its own type; the quota check sums by model, version and type and subtracts the deployment already in the account; `--check models` warns at 270 days but not at 280 and reads a second environment's account through `accounts/read` and `accounts/deployments/read` only; check 13 runs only in `load`; check 14 fails 3 domains on Free and passes 5 on Standard. Deployed: the CI preflight passes for the shipped `dev` and `prod` files.
